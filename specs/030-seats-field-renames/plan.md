## Implementation Plan

### Phase 1: Fix SKILL.md write flows

Three targeted edits to `skills/seats/SKILL.md`:

**Edit 1 — Create Seat root body** (`group_id` → `team_id`):
- Location: Flow: Create Seat → Step 4 → Root seat bash block
- Change: `'{"name":"NAME","group_id":TEAM_ID}'` → `'{"name":"NAME","team_id":TEAM_ID}'`

**Edit 2 — Update Seat `--owner` mapping** (`accountability_owner_id` → `seat_owner_id`):
- Location: Flow: Update Seat → Step 2 → Build PATCH body table
- Change: `"accountability_owner_id": {uid}` → `"seat_owner_id": {uid}`

**Edit 3 — Direct Reports table** (remove Owner column):
- Location: Flow: View Seat Details → Step 3 → Direct Reports display block
- Change: `| ID | Name | Owner |` + `| {id} | {name} | {owner or Vacant} |` → `| ID | Name |` + `| {id} | {name} |`

### Phase 2: Fix api-reference.md (master)

Three targeted updates to `api-reference.md`:

**Edit 1 — POST /seats description**:
- Change: `group_id or parent_id` → `team_id or parent_id`
- Change: `accountability_owner_id?` → `seat_owner_id?`

**Edit 2 — PATCH /seats/{id} description**:
- Change: `accountability_owner_id?` → `seat_owner_id?`

**Edit 3 — Terminology table (seat owner row)**:
- Change: `accountability_owner_id` → `seat_owner_id`

### Phase 3: Sync and verify

1. Run `/sync-plugin` to copy master `api-reference.md` to `skills/seats/references/api-reference.md` and bump plugin version.
2. Verify no remaining references to `group_id` (in seat context), `accountability_owner_id`, or `SeatSimple` Owner column in SKILL.md.
3. Commit and push.
