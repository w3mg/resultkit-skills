# Quickstart: rkit:weekly

**Prerequisite**: `/rkit:setup` completed.

## 1. View Full Weekly

```
/rkit:weekly
```

## 2. View Single Column

```
/rkit:weekly next
```

## 3. Move Item

```
/rkit:weekly move 42 done
```

## 4. Add Item

```
/rkit:weekly add 55
```

## 5. Remove Item

```
/rkit:weekly remove 42
```

## 6. Different Team

```
/rkit:weekly --team 7
```

## 7. Level 10 Synonym

```
/rkit:level10
```
